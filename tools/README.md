# Tools

Local helper scripts for building and previewing the static album.

- `build_encrypted_album.py` builds `assets/encrypted` from `PRIVATE_PHOTOS`.
- `dev_server.py` starts a local GitHub Pages-like preview with custom `404.html`.

Run the root `.bat` files for normal use:

- `BUILD_ENCRYPTED_ALBUM.bat`
- `START_GALLERY.bat`
