# Tools

Local helper scripts for building and previewing the static album.

- `build_encrypted_album.py` builds `assets/encrypted` from `private/photos`.
- `dev_server.py` starts a local GitHub Pages-like preview with the root `404.html` redirect.

Run the root `.bat` files for normal use:

- `scripts/windows/BUILD_ENCRYPTED_ALBUM.bat`
- `scripts/windows/START_GALLERY.bat`
