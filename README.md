# Our Story Secure Pages Edition

Готовая версия для GitHub Pages с:

- длинным случайным именем репозитория;
- запретом индексации;
- AES-256-GCM шифрованием фотографий;
- PBKDF2-SHA-256, 600 000 итераций;
- зашифрованным манифестом;
- автоматическим сжатием фотографий и отдельными зашифрованными превью;
- ленивой расшифровкой: сайт не скачивает весь альбом сразу;
- случайными именами зашифрованных файлов без исходных названий фото;
- строгими браузерными политиками и без внешних шрифтов/трекеров;
- отсутствием кнопки выбора фотографий на опубликованном сайте;
- художественными заглушками до ввода правильной фразы.

## Подготовка фотографий

1. Распакуйте архив.
2. Положите фотографии с любыми названиями в `PRIVATE_PHOTOS`.
3. Запустите `BUILD_ENCRYPTED_ALBUM.bat`.
4. Дважды введите секретную фразу.
5. Скрипт создаст содержимое `assets/encrypted`.

Папка `PRIVATE_PHOTOS` нужна только для сборки. Не загружайте её на GitHub.

Сборщик устанавливает `cryptography` и `Pillow`, если их нет. Pillow нужен, чтобы перед шифрованием уменьшить фото до разумного размера и создать превью. Это делает сайт быстрее и снижает нагрузку на телефон.

## Публикация

Загрузите в корень публичного репозитория все файлы проекта, КРОМЕ папки `PRIVATE_PHOTOS`.

В GitHub:

`Settings → Pages → Deploy from a branch → main → /(root)`

## Безопасность

GitHub Pages остаётся публичным хостингом. Длинная ссылка снижает вероятность случайного обнаружения, а `robots.txt` и `noindex` просят поисковики не индексировать сайт.

Реальную защиту фотографий обеспечивает шифрование. Без секретной фразы файлы `.enc` и манифест нельзя нормально прочитать.

Важно: GitHub Pages остаётся публичным. Любой человек, получивший ссылку, может скачать зашифрованные файлы и пытаться подбирать фразу офлайн. Поэтому секретная фраза должна быть действительно сильной.

Секретную фразу:

- не записывайте в код;
- не называйте очевидной датой;
- передавайте отдельно от ссылки;
- используйте хотя бы 5–7 случайных слов или 20+ символов;
- не отправляйте ссылку и фразу одним сообщением;
- если ссылка или фраза утекли, пересоберите альбом с новой фразой.

Опция `Запомнить этот браузер` сохраняет не саму фразу, а ключ расшифровки в хранилище браузера для текущего домена. Это удобно для личного телефона или компьютера, но на чужих или общих устройствах эту опцию лучше отключать.

## Обновление фотографий

Замените содержимое `PRIVATE_PHOTOS`, снова запустите сборщик и загрузите обновлённую папку `assets/encrypted` в репозиторий.
